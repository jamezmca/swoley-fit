
# Swoley Fit

## Introduction

Swoley Fit is a comprehensive fitness tracking application designed to help users manage, monitor, and optimize their workout routines and physical progress. It focuses on workout routines and fitness related UI for a streamlined experience. The repository provides a React single page application that implements the core fitness tracking features.

The project aims to simplify the process of tracking physical activity by providing a clean interface for browsing and planning workouts. Swoley Fit is suitable for both individual use and as a foundation for further fitness app development.

## Usage

Swoley Fit offers a range of features to empower users in their fitness journey:

- Navigate between different workout related sections.
- Browse predefined exercises and workout sections.
- Build personalized workout routines.
- Log workouts and track progress.

### Common User Flows

- **App Navigation:** Move between the main workout related pages to explore available content.
- **Exercise Viewing:** View predefined exercises, including details like muscle groups, equipment, and instructions.
- **Routine Exploration:** Explore routines that combine multiple exercises and support different workout goals.
- **Progress Tracking:** Record completed workouts, log exercise statistics, and monitor improvements over time.

## Installation

To install and run Swoley Fit locally, follow these steps:

### Prerequisites

- Node.js (version 14.x or higher recommended)
- npm (Node Package Manager)

### Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/jamezmca/swoley-fit
   cd swoley-fit
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```


3. **Start the Application**

   - For development:
     ```bash
     npm run dev
     ```

   - For production:
     ```bash
     npm start
     ```

4. **Access the Application**

   The development server will be running at `http://localhost:5173` (or the port you specified).

5. **Application Documentation**

   Explore the application by running it locally and reviewing the React components in the source code.
